Ekspor & Hosting Website Anda

Website ini menyimpan profil dan tugas Anda langsung di **LocalStorage browser Anda**. Agar tugas baru yang Anda input dapat diakses permanen saat di-hosting, unduh versi HTML terbaru di bawah ini.

Bagaimana caranya?

  1. Tambahkan tugas atau edit profil Anda sesuka hati di website ini.
  2. Klik tombol **"Unduh HTML Siap Hosting"** di bawah.
  3. File `index.html` baru akan terunduh dengan data inputan Anda sebagai bawaan/default baru.
  4. Unggah file HTML baru tersebut ke platform hosting statis seperti **GitHub Pages**, **Netlify**, atau **Vercel**!
